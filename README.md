# bodegas-frontend

Frontend en Angular para el sistema de bodegas y productos.

## Requisitos

- Node.js
- Tener corriendo el backend (bodegas-backend) en http://localhost:8080

## Ejecución

Instalar dependencias:

```
npm install
```

Iniciar la aplicación:

```
npm start
```

Abrir http://localhost:4200
